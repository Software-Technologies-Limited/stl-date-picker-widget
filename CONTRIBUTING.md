# Contributing

Bug reports and pull requests are welcome on GitHub. Before submitting a
change:

1. Base the work on the default branch.
2. Run the development checks documented in the README.
3. Keep changes focused and explain compatibility implications.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.

By contributing, you agree that your contribution is licensed under the
project's BSD-3-Clause license.
